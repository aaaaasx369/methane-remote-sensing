# Third-party code intentionally not vendored

This curated repository contains project-authored or project-modified code collected from the Mac, lab server, and FIR on 2026-08-17.

The following were intentionally not copied into this repository:

- the unmodified upstream MethaneFuse clone and its `thirdparty/` tree;
- the separately supplied MethaneAIR controlled-release R/WRF code bundle;
- Stanford-controlled-release notebooks distributed with the external dataset;
- Python environments, Google Cloud SDK files, caches, and site-packages.

Project-specific modifications to MethaneFuse internals are preserved under `methanefuse_overrides/`. The upstream repository should be tracked separately rather than copied wholesale into this research-code repository.

Before making the repository public, choose an appropriate license with the project supervisor and verify the license/attribution requirements of all external datasets and upstream software.
